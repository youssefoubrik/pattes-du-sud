# UX principles

- Start from what visitors need to understand or do. Make the next useful action clear.
- Explain choices, costs, and consequences before asking for commitment. Be clear about external handoffs.
- Remove unnecessary steps, choices, and copy. Do not make visitors infer how an action works.
- Give clear feedback about success, errors, and next steps.
- Design for small screens, keyboard use, and assistive technology.
- Judge success by completed visitor tasks, not clicks alone.
