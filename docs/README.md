# Project principles

Use these short guides when designing or changing the site:

- [UX](ux.md): help visitors complete their task with clarity and confidence.
- [UI](ui.md): make the interface calm, consistent, responsive, and accessible.
- [Fundraising](fundraising.md): make giving trustworthy, clear, and satisfying before and after payment.
- [Content](content.md): routes, localization, editable content, SEO, and verified facts.
- [Code quality and engineering](code-quality.md): implementation, performance, and errors.

`AGENTS.md` contains core project and work rules. These guides hold the detailed requirements by topic.
