# UI principles

- Follow the existing design system, semantic tokens, and shared components. Do not re-document or recreate component-level styles already in code.
- Keep hierarchy clear and visual weight restrained. Use spacing and grouping before adding borders, cards, or decoration.
- Keep the site warm, calm, trustworthy, and recognizably nonprofit.
- Make text readable and controls accessible across screen sizes. Use visible focus and sufficient contrast; never rely on color alone.
- Keep motion subtle and respect reduced-motion preferences.
